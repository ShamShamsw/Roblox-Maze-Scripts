# Required Functionality

1. Humanoid and HumanoidRootPart components

2. Detection radius

3. Pathfinding settings

## Required Changes you may have to make

* When a player is detected.
* When the enemy begins chasing.
* When a new path is calculated.
* When the enemy loses its target.
* When the enemy returns to its spawn position

The basic error handling makes the script reusable across multiple enemy NPCs.
